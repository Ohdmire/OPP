# OPP 版本变更记录

本文档按版本记录 OPP 的主要功能、界面和兼容性变化。

## v0.4.0

- 重构前端页面结构与共享展示逻辑，统一交互组件、视觉变量和加载状态，降低大型页面的职责耦合。
- 相似谱面高级设置支持动态/手动权重持久化；当数据集缺少动态统计时提供明确的手动降级提示。
- 个性化推荐支持控制快速首屏的种子数量，并在后台补全完整推荐结果。
- 整理后端相似谱面请求边界与测试，保持 Analyzer v3 数据集兼容性检查。
- 统一 README、快速入门、数据集说明、架构文档和发布版本号。

## v0.3.5

- 相似谱面分析器升级到 Analyzer v3，以 Slider 维度替换 Flashlight，并校验数据集算法版本；Analyzer v2 数据集需要重新生成。
- 相似谱面新增“最近成绩推荐”和“BP 推荐”，支持聚合多个成绩种子、去重结果并展示推荐来源。
- 在线谱面下载新增 Hinai 镜像并默认启用多镜像自动回退；批量队列补充全局进度、取消状态和单张快捷下载。
- 本地谱面可直接调用网易云音乐客户端搜索对应歌曲。
- 新增检测到 osu! Stable 或 osu!lazer 后自动启动 tosu 的设置项。
- Trainer 页面会在当前会话中保留谱面、参数与生成结果，并修正返回本地谱面页面的导航。
- 统一 Rust 代码格式，修复严格 Clippy 检查发现的问题，并补充在线谱面与 Trainer 回归测试。

## v0.3.0a

- 修复托盘左键恢复主窗口逻辑的静态检查错误，确保发布构建可以通过严格 Clippy 校验。

## v0.3.0

- 新增一级 tosu 直播页面：可引导安装、静默启动和停止 tosu，并显示 v2 API 实时游戏数据与配置网站入口。
- 新增 tosu-lyrics 集成：引导安装 `tosu-proxy.exe`，在 OPP 启动 tosu 时自动启动歌词代理，并提供 OBS 歌词地址。
- tosu 运行日志新增 Windows 非 UTF-8 输出解码、日志级别展示和问题级别筛选。
- 调整侧栏：tosu 与工具集合并列，放大并上移 osu! 启动入口；恢复关于页感谢与关联项目，并补全 README 关联仓库。

## v0.2.8

- 新增本地回放识别、谱面提交状态校验与 o!rdr 视频渲染。
- 支持多样化渲染选项、实时队列进度与视频导出。
- 统一截图、回放、渲染页面导航，并优化回放搜索和设置目录配置。

## v0.2.6

- 将项目定位统一为一站式 osu! 工具集合。
- 左下角用户 ID 旁新增按钮，可使用系统默认浏览器打开 osu! 个人主页。
- 游戏总结弹窗增加 Tips：嘛，如果拘泥于数据就会让游戏本来的乐趣消失哦。
- 启动 osu! 与后台进程检测隐藏 Windows 控制台窗口，避免 CMD 反复弹出。
- 更新关于页、README 和应用版本号至 0.2.6。

## v0.2.5

- 本地截图和回放改为左侧对象列表、右侧主体预览布局。
- 支持资源管理器定位、复制文件路径和截图复制到系统剪贴板。
- 设置页增加关于、协议、依赖、参考项目和感谢信息。
- 新增 MIT License。

## v0.2.4

- 建立在线资料、成绩、本地谱面、本地 Skin 和游戏会话等基础功能。
- 支持 osu! OAuth 登录、个人资料读取和本地资源扫描。
- 支持 Stable 与 Lazer 客户端的数据源检测和本地分析。

## 版本维护约定

- 用户可见功能、界面布局、协议和兼容性变化都应在本文件新增版本条目。
- 版本号需同步更新 `package.json`、`src-tauri/tauri.conf.json` 和 `src-tauri/Cargo.toml`。
